# HatchMind · 나의 작은 숲

## 휴대폰·공개 링크로 플레이

**[HatchMind 바로 플레이](https://jinha381.github.io/Abraxas/)**

회원가입, 앱 설치, 지갑 연결 없이 누구나 링크로 접속합니다. 각 방문자는 혼자 플레이하며 다른 유저와 통신하지 않습니다. 게임 안의 user1~user4는 같은 기기에서 바꿔 보는 플레이 계정입니다. 시작할 때 user1은 토끼 듀이, user2는 거북 셸리, user3는 기니피그 피치, user4는 족제비 액시를 키웁니다. 이들은 각 계정의 첫 뉴로링이며, 만남으로 태어난 알이나 선물 받은 알을 더 키울 수 있습니다. 계정 이름과 펫 이름은 분리되고, 계정 선택기에는 user1~user4만 표시됩니다. 만남·동의·선물 코드도 같은 브라우저 안의 체험입니다.

진행 상황은 브라우저 localStorage에만 저장됩니다. 기기·브라우저·시크릿 창마다 별도이며 저장 공간을 지우면 초기화됩니다. 로컬 HTML 파일로 플레이한 기록과 공개 HTTPS 링크의 기록도 서로 별도입니다.

상단의 공유 버튼은 휴대폰 공유 메뉴를 열거나 공개 링크를 복사합니다. 저장 데이터나 선물 코드를 링크에 넣지 않습니다.

### 배포

`.github/workflows/pages.yml`이 main의 game/ 변경 시 GitHub Pages를 자동 갱신합니다. `scripts/build-game.cjs`가 HTML·CSS·JS·이미지만 배포 파일에 넣습니다. 컨트랙트·개인키·로컬 저장·테스트 서버·백업 파일은 웹사이트에 배포하지 않습니다.

공개 경로에서의 DOM 확인 12개(기본 화면, 돌봄 저장, 6개 화면, URL 복사·모바일 공유, 개인 플레이 안내, 저장 분리, 스프라이트, 연결 코드 부재, 배포 범위, 모바일 CSS, 런타임 오류)를 통과했습니다.


그래픽 폴더의 원본 PNG 9개를 활용한 한국어 게임 화면 HTML입니다. 외부 CDN, 프레임워크, 추가 패키지 없이 동작합니다.

## 체험 기능

- 정원: 네 캐릭터 선택, 먹이 주기·함께 놀기·쉬어 가기, 포만감·에너지·친밀도 변화
- 작은 친구들: 전체/내 친구 필터, 성장 단계별 캐릭터 표시, 유전 파츠·진화 디자인 보기
- 새로운 만남: 서로 다른 두 펫 선택, 두 소유자 동의 체험, 같은 소유자의 두 펫 허용, 알 생성
- 알 보관함: 3초 간격 단계 성장, 부화 연출, 체험 코드로 선물·청구, 30초 만료·선물자 직접 회수
- 우리의 이야기: 생성된 알의 부모 관계, 성장·진화 시트
- 위쪽 계정 선택기로 user1~user4 계정을 전환
- 낮/밤 테마, 선택형 효과음, 키보드 조작·반응형 레이아웃, reduced-motion 지원
- 브라우저 저장 공간이 허용되면 진행 상황을 로컬에 보관

## 짧은 체험 순서

1. 기본 user1 정원에서 먹이·놀이·휴식을 눌러 봅니다.
2. 새로운 만남에서 듀이와 셸리를 선택하고 만남을 요청합니다.
3. 상대 플레이 계정으로 동의 체험을 한 뒤 새로운 알을 만납니다.
4. 알을 부화시키거나 선물 코드를 만듭니다.
5. 다른 플레이 계정으로 전환해 같은 브라우저에서 코드를 청구합니다.
6. 만료·회수는 선물 생성 시 30초 옵션을 선택하고, 보낸 계정으로 돌아와 직접 회수합니다.

## 구현 범위

이 화면은 브라우저에서 동작하는 프런트엔드 프로토타입입니다. 실제 지갑 연결·서명·Anchor RPC 호출·NFT 전송은 연결하지 않았습니다. 계정 선택기는 이 브라우저의 플레이 계정을 전환하며 실제 개인키를 생성하거나 요구하지 않습니다.

교배 결과의 예측 가능한 UI 이미지, 로컬 저장 데이터와 체험 코드는 온체인 유전 계산이나 Gift PDA를 대체하지 않습니다. 실제 결합 시 기존 컨트랙트의 Core 소유자 재검증, seed 규칙, 요청·만료·중복 검증을 그대로 사용해야 합니다.

## UI 개편 (2026-11-14)

- 대시보드형 사이드바를 게임식 상단 탭 바로 바꾸고, 남색 외곽선·파스텔 색의 도트 게임 창 스타일로 전체를 다시 디자인했습니다.
- 캐릭터는 시안 이미지를 SVG로 잘라 쓰던 방식에서, 배경을 지우고 하나씩 떼어낸 투명 스프라이트(assets/sprites/)로 바꿨습니다. 옆 캐릭터 조각·표 선이 더 이상 보이지 않습니다.
- 정원 화면은 하늘·땅이 있는 무대 위에 친구들이 서 있고, 선택한 친구가 크게 앞에 나와 말풍선으로 말합니다.
- 팀원 기획(뉴로링 4기본형 dewy·Shelly·Peachy·Axy, 성향 진화 트리)을 반영해 이름을 듀이(토끼)·셸리(거북)·피치(기니피그)·액시(족제비)로 맞추고, 성향 트리 화면(#traits)을 추가했습니다. 성향 노드 8개는 돌봄 횟수·친밀도·기본형 조건으로 획득합니다.
- 기능 로직은 바꾸지 않았습니다. 이전 파일은 _backup/ 에 있습니다.

JavaScript 문법 검사와 로컬 HTTP·이미지 200 응답을 확인했습니다. 실제 HTML·JavaScript를 실행한 DOM 검증 17개(돌봄, 소유자 제한, 도감, 두 소유자 동의, 같은 지갑 교배, 부화, 성장 대기·진화, 선물·만료·회수·중복 청구, 계보, 테마, 저장 복원, CSS 구문, PNG)를 통과했습니다.

- **스프라이트 개선**: `assets/px/` — 원본에서 돌·풀·그림자 소품을 떼어 낸 캐릭터 단독 스프라이트 + 눈 깜빡임(-blink)·웃는 눈(-happy) 프레임 자동 생성. 원본 `assets/sprites/`는 그대로 둠.

## 산책로 광장과 친구 맺기

- 정원에서 **산책 가기**를 누르면 감각(후각) 입력 학습 후 장소가 **산책로 광장**으로 바뀝니다.
- 광장에서는 user1~user4 각 계정의 뉴로링(계정마다 가장 많이 자란 한 마리)을 한꺼번에 만납니다.
- 다른 뉴로링을 누르거나 **인사하기**를 누르면 서로 인사하지만, 이것만으로는 친구가 되지 않습니다.
- 카드의 **친구 맺기**를 눌렀을 때만 계정 대 계정 친구 관계가 생기고(양방향), **친구 끊기**로 해제할 수 있습니다.
- **만남(교배)** 의 두 번째 뉴로링은 내 뉴로링이나 친구 계정의 뉴로링 중에서만 고를 수 있습니다.
- 친구들 화면에 **친구 계정** 필터가 추가되었습니다.

## 향기 실험실 (버섯체 연합학습 미션)

- 정원의 **향기 실험** 버튼(키보드 3)으로 들어갑니다.
- 모델: 향기 3종(딸기·민트·산딸기) → 케니언 세포(KC) 12개의 희소 부호 → 출력 뉴런(MBON) 접근 가치. 산딸기는 딸기와 KC 4개를 공유합니다.
- 학습은 도파민(DAN) 보상이 있을 때 활성 KC→MBON 가소성에만 남습니다(Δw = 0.35·r·(1−w)). 실측 구조는 바꾸지 않습니다.
- 배고픔은 기억(가중치)을 바꾸지 않고 행동 표현만 조절합니다(게이트 0.25+0.75·배고픔).
- 미션 6단계: ① 학습 전 선호 측정(10회 선택) ② 딸기 향+당근 연합 3회 ③ 재검사 ④ 배고플 때/배부를 때 비교 ⑤ 산딸기 전이·보상 없는 소거 ⑥ 가상 차단(학습 기억은 그대로 두고 모델의 KC→MBON 출력만 꺼서 다시 측정).
- 측정 기록에는 실제 10회 선택 결과와 모델 선택 확률을 함께 보여 줍니다. KC 12개로 줄인 추상 모델이며, 막대와 점등은 모델 계산값이지 실제 뉴런 활동이 아닙니다. FlyWire 실측 부분회로는 뉴런 ID·연결표 검증 후 이식할 예정입니다.
- 광장과 실험실에서도 각 기본형의 말투를 유지합니다. 처음 만난 상대·친구·친구 맺기, 실험 전 선호·학습 후 회상·첫 보상·반복 보상·보상 없는 노출을 구별합니다. 상태 비교 대사는 가상의 배고픔·포만감을 떠올리는 표현을 사용하며 실제 돌봄 수치가 변했다고 말하지 않습니다. 정원으로 돌아올 때도 광장과 실험실에서 돌아온 상황을 구분합니다.

## 경험 지문 (NeuroProof 로컬 미리보기)

- 향기 실험실의 이벤트(측정·연합·소거·민트 노출·가상 차단·초기화)마다 지문을 만들어 펫별 해시 사슬(`p.proof.events`)에 보관합니다.
- 해시 입력은 정해진 순서의 문자열입니다: `HM-NEUROPROOF-v1 | 이전 해시 | 순번 | 펫 ID | 모델 버전(mb-kc12-v1) | 이벤트 | 향기 | 배고픔 | 결과 | KC→MBON 가중치 12개`. 소수 값은 ×1000 정수로 바꿔 넣어 구현마다 같은 문자열이 나오게 합니다.
- SHA-256은 외부 라이브러리 없이 `app.js` 안에서 계산합니다(Node `crypto` 결과와 대조 확인).
- **다시 계산해 검증**을 누르면 모든 기록을 처음부터 재계산해 이전 해시·순번·내용을 대조합니다. 기록 하나의 값만 바꿔도 해당 순번에서 불일치가 표시됩니다.
- 실험 초기화를 해도 지문 사슬은 지우지 않고 `reset` 이벤트를 추가합니다.
- 브라우저 안의 해시 사슬이며 온체인 기록이 아닙니다. PDA 기록과 서명 권한은 후속 단계입니다.

## 회로 표현 원칙

- 정원의 12노드 회로는 FlyWire 연구로 알려진 감각→중추→행동 경로를 참고한 추상 모델입니다. 실측 회로나 실제 뇌 활동이 아니며, 화면의 불빛은 모델 예측 활성입니다.
- 각 노드에 마우스를 올리면 대응하는 뇌 영역 설명(AL·PN, MB·KC·MBON, LH, CX, 시각엽, 존스턴 기관 등)이 나옵니다.
