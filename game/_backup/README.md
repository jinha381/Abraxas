# HatchMind · 나의 작은 숲

그래픽 폴더의 원본 PNG 9개를 활용한 한국어 게임 화면 HTML입니다. 외부 CDN, 프레임워크, 추가 패키지 없이 동작합니다.

## 열기

index.html을 브라우저에서 바로 열거나, 프로젝트 루트에서 아래 명령으로 로컬 미리보기를 실행합니다.

```powershell
node game/server.cjs
```

http://127.0.0.1:4173

## 체험 기능

- 정원: 네 캐릭터 선택, 먹이 주기·함께 놀기·쉬어 가기, 포만감·에너지·친밀도 변화
- 작은 친구들: 전체/내 친구 필터, 성장 단계별 캐릭터 표시, 유전 파츠·진화 디자인 보기
- 새로운 만남: 서로 다른 두 펫 선택, 두 소유자 동의 체험, 같은 소유자의 두 펫 허용, 알 생성
- 알 보관함: 3초 간격 단계 성장, 부화 연출, 체험 코드로 선물·청구, 30초 만료·선물자 직접 회수
- 우리의 이야기: 생성된 알의 부모 관계, 성장·진화 시트
- 위쪽 지갑 역할 선택기로 dewey·axie·kitty·tama를 전환
- 낮/밤 테마, 선택형 효과음, 키보드 조작·반응형 레이아웃, reduced-motion 지원
- 브라우저 저장 공간이 허용되면 진행 상황을 로컬에 보관

## 짧은 체험 순서

1. 기본 dewey 정원에서 먹이·놀이·휴식을 눌러 봅니다.
2. 새로운 만남에서 듀이와 모루를 선택하고 만남을 요청합니다.
3. 상대 지갑 역할로 동의 체험을 한 뒤 새로운 알을 만납니다.
4. 알을 부화시키거나 선물 코드를 만듭니다.
5. 다른 지갑 역할로 전환해 같은 브라우저에서 코드를 청구합니다.
6. 만료·회수는 선물 생성 시 30초 옵션을 선택하고, 보낸 지갑으로 돌아와 직접 회수합니다.

## 구현 범위

이 화면은 브라우저에서 동작하는 프런트엔드 프로토타입입니다. 실제 지갑 연결·서명·Anchor RPC 호출·NFT 전송은 연결하지 않았습니다. 체험 지갑은 역할 선택이며 실제 개인키를 생성하거나 요구하지 않습니다.

교배 결과의 예측 가능한 UI 이미지, 로컬 저장 데이터와 체험 코드는 온체인 유전 계산이나 Gift PDA를 대체하지 않습니다. 실제 결합 시 기존 컨트랙트의 Core 소유자 재검증, seed 규칙, 요청·만료·중복 검증을 그대로 사용해야 합니다.

## 이미지

assets/에는 원본을 그대로 복사했습니다. SVG viewBox로 필요한 영역만 화면에 표시하며 PNG 원본은 수정하지 않았습니다.

- reference.png: 초기 네 성장기 캐릭터와 작은 서식지
- nursery.png: 알·갓 부화·아기
- evolution.png: 네 타입의 진화 갈래
- walking.png: 거북의 걷기 4프레임
- hatching.png: 기니피그의 부화 5프레임
- parts.png, hybrid.png, rabbit-parts.png, weasel-evolution.png: 유전·골격·진화 설명

컨트랙트와 기존 테스트 파일은 이 화면 제작으로 변경하지 않습니다.

## 확인한 항목

JavaScript 문법 검사와 로컬 HTTP·이미지 200 응답을 확인했습니다. 실제 HTML·JavaScript를 실행한 DOM 검증 17개(돌봄, 소유자 제한, 도감, 두 소유자 동의, 같은 지갑 교배, 부화, 성장 대기·진화, 선물·만료·회수·중복 청구, 계보, 테마, 저장 복원, CSS 구문, PNG)를 통과했습니다.

브라우저 연결 호스트를 사용할 수 없고 Chrome 창 접근도 실패하여 실제 브라우저의 시각 배치와 모바일 화면 캡처는 검증하지 못했습니다. 반응형 CSS는 포함되어 있습니다. DOM 검증은 실제 브라우저 렌더링 검증을 대신하지 않습니다.
