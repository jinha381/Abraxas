## 본문·표·그림의 범위

- 2.2·4.1·5.1절: 브라우저 게임과 로컬 검증기의 계약은 독립 구현입니다. 지갑·RPC 연동, 서버·DB, 실제 다중 사용자 통신은 계획입니다. 그림 1·8은 서비스 구상과 목표 구조로 읽습니다.
- 2.3절: 전체 외형 유전형 공간은 최대 16,384가지, 고정 부모 한 쌍은 최대 128가지입니다. 계약은 7개 지표를 상속하고 화면은 완성 스프라이트를 고릅니다. 559장은 제출본에 기재된 보유 리소스 수이며 저장소의 개별 이미지 파일 수나 합성 렌더러 구현 수가 아닙니다.
- 3.1절: 현재 보상은 상호작용·상태로 자동 계산합니다. 그림 3의 칭찬·기다리기 등 명시적 사후 피드백은 후속 기능입니다.
- 3.3절: 향기 학습은 돌봄 횟수와 기질을 통해 성향 노드에 간접 반영합니다. 선호도 변화·소거·안정성 기반 판정과 기억 일기는 계획입니다. 표 1의 역전학습·반응 속도·방향 표상은 확장 목표를 포함합니다.
- 3.4·4.2절: 자기 소유의 서로 다른 두 펫끼리도 교배합니다. 다른 계정의 펫은 브라우저에서 친구로 등록해야 선택할 수 있습니다. 표 6의 “친구만 교배 상대”는 다른 계정의 상대 선택에 대한 축약이며, 계약의 친구 검증을 뜻하지 않습니다.
- 4.2절: 계약의 초기 펫은 알, 브라우저의 초기 네 펫은 체험 편의를 위한 성장기입니다. 성향·진화 갈래는 오프체인 판정이며 계약은 소유권과 단계·시간 등을 검사합니다.
- 4.3절: NeuroProof는 최근 60개 로컬 기록의 내부 일관성 검사입니다. 기록 삭제·전체 재작성 탐지, 현재 상태 대조·재실행 방지·외부 체크포인트·PDA·서명 검증은 계획입니다. NeuroVision과도 독립적입니다.
- 5.2절: 47개 온체인 테스트는 로컬 검증기 결과이며 devnet 배포나 외부 보안 감사 결과가 아닙니다. R01~R03은 공격 성공을 재현한 미해결 위험입니다.

최종본에는 이전 문서의 “경험으로 배운 내용은 자손에게 직접 유전되지 않는다”는 문장이 없습니다. 현재 게임의 부모 정원 회로 가중치 평균·변동 규칙은 별도 데모 규칙으로 문서화하고 유지합니다. 이는 계약의 외형 유전이나 생물학적 학습 유전을 뜻하지 않습니다.
