## 현재 상태로 읽기

- 향기 실험실은 KC 12개 추상 모델로 연합학습, 상태 비교, 전이·소거, KC→MBON 출력 차단을 구현했습니다. 참고 PDF에 있는 “설계 완료”·“차단은 후속 계획” 표기는 현재 게임보다 이전 단계입니다.
- NeuroProof는 최근 60개 브라우저 기록의 해시 사슬 일관성 검사를 구현했습니다. 해설 PDF의 PDA·NFT 연결, 외부 기준값·서명 권한·재실행 방지는 여전히 제안입니다.
- NeuroVision은 독립 영상입니다. 이 영상이 게임 회로의 실행 로그이거나 NeuroProof·실제 온체인 거래와 연결되어 있다고 해석하지 않습니다.
- 실제 FlyWire 시냅스 연결표 이식, 실측·셔플 회로 비교, 동일 난수 시드를 이용한 대조 실험, 길찾기와 서사 일기는 후속 범위입니다. 현재 선택 시뮬레이션은 `Math.random()`을 사용합니다.
- 게임 G/P/S 등의 개념도와 향후 데이터 구조는 실제 초파리 DNA·의식·기억을 복제했다는 주장이 아닙니다. 구체적인 현재 동작은 [게임 문서](../../game/README.md)를 따릅니다.
